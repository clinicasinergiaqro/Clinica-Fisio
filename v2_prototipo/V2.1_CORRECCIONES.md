## 0. Defecto central corregido

El núcleo V2 razonaba por **coincidencia de palabras** y las pruebas estaban **declaradas** (Excel), no ejecutables. V2.1:

1. Separa **extracción de hechos** (con negación, temporalidad, lateralidad, región, antecedente personal vs familiar, lectura de SOAP fechado) de **reglas deterministas independientes**.
2. Cada hecho conserva su **evidencia** (campo + fragmento literal citado) → trazabilidad real.
3. El JSON del generador es la **única fuente de verdad**: el PDF y el prototipo visual se construyen **desde ese JSON** (no hay prosa “mejorada” aparte).
4. Las **pruebas son ejecutables** (`node v2_prototipo/tests/pruebas_v2.js`) y reproducen **cada error** de la auditoría. **42/42 PASA**, 3 pendientes declarados honestamente.

## 4. Cómo correr / reproducir

```
# Pruebas ejecutables (unitarias + integración)
node v2_prototipo/tests/pruebas_v2.js        # 42/42 PASA, exit 0
```
