# SINERGIA — parche visual de ChatGPT (4 pantallas prioritarias)

Base: Sinergia_V2_navegable.zip aportado por el usuario. No es una app nueva ni una sustitución de index.html de producción. Los dos archivos del parche se cargan DESPUÉS de sinergia_v2.css y sinergia_v2.js. El ZIP incluye una copia de la réplica con el parche ya enlazado. No copiar el index.html de demo a producción.

## Integración para Claude
1. Copiar sinergia_fidelidad.css y sinergia_fidelidad.js a la carpeta de integración de la rama aislada; ajustar build_v2.py para cargar ambos después de la capa V2 actual. Alternativamente incorporar sus reglas a las plantillas V2 con el mismo orden de cascada. No modificar el motor clínico.
2. Abrir `replica_v2/index.html` con un servidor local aislado (`python3 -m http.server 8080`, desde replica_v2; acceder a localhost:8080). El autoarranque de la demo muestra Agenda; para ver login, usar el cierre de sesión de la demo o desactivar el autoarranque **solo en la réplica**. No conectar a backend real. Bloquear red externa en pruebas, revisar configuración de service worker y rutas de backend antes de ejecutar.
3. Comparar con capturas de referencia de 390 px (login, agenda, expediente, SOAP). La composición prioriza seguridad visible antes de nueva sesión, mosaico con los nueve módulos existentes y formularios compactos. No reemplazar iconos o textos que tengan significado clínico.
4. No sustituir `renderExpediente`, `renderSOAPForm`, `guardarSOAP`, `nuevaSesionRapida`, autenticación, persistencia, permisos ni biomecánica. El acceso Nueva sesión se crea solo si el FAB original está disponible, y reenvía el click al mismo botón. El nodo original permanece. El editor SOAP conserva sus inputs y controles, con identificación informativa plegable y fecha editable. Los cambios de orden requieren prueba de regresión, incluyendo edición de SOAP, descarga, nuevo episodio, dermatofuncional, pacientes migrados y roles.
5. Si cambia el DOM real respecto a la base, adaptar selectores de presentación y validar; no crear simulaciones. Revisar el MutationObserver y comportamiento al re-renderizar. Quitar ambos enlaces para revertir. No merge ni deploy.
